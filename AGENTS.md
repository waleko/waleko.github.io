# AGENTS.md

## Cursor Cloud specific instructions

This repo is a **Jekyll static site** (GitHub Pages personal portfolio for Alexander Kovrigin). There is no backend, database, API, or automated test/lint suite — the only "service" is the Jekyll build/dev server.

### Running the site
- Build: `jekyll build` (output goes to `_site/`, which is gitignored).
- Dev server (with live reload): `jekyll serve --host 0.0.0.0 --port 4000 --livereload`. It auto-regenerates on file changes; new/edited posts in `_posts/` appear after a few seconds.

### Non-obvious gotchas
- There is **no `Gemfile`/`Gemfile.lock`** in the repo (both are gitignored), and **no root `index.html`/`index.md`**. Don't add them expecting them to be tracked.
- Every post in `_posts/*.markdown` sets `permalink: /` and uses the `default` layout, which ignores post `{{ content }}` and always renders the bio + a Liquid loop over all `research`-category posts. The homepage (`_site/index.html`) is therefore generated by whichever post is "last". As a result, `jekyll build` prints a **`Conflict: The following destination is shared by multiple files`** warning for `_site/index.html` — this is **expected**, not an error.
- To add a research entry to the homepage, add a `_posts/YYYY-MM-DD-name.markdown` file with front matter `categories: research` plus `title`, `authors`, `venue`, `image`, and optional link fields (`arxiv`, `code`, `hf`, etc.). Thumbnails are served from `/tn{{post.image}}`.
- Local dev uses Jekyll 4.x; production is GitHub Pages (Jekyll 3.x). Minor rendering differences are possible but unlikely for this simple site.
- `_make_thumbnails.sh` requires ImageMagick (`convert`) and is only needed when adding/updating research images.
